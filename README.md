# Voxel Sandbox

Небольшая 3D-песочница в духе Minecraft на Three.js, запускается через Node.js.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Управление

- WASD — движение
- Space — прыжок
- Shift — спринт
- ЛКМ — удалить блок
- ПКМ — поставить блок
- Esc — освободить курсор
